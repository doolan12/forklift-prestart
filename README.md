# Forklift pre-start check

A single-page, phone-friendly pre-start checklist for Toyota electric forklifts (7FBE15, 7FBE18, 8FBE18 and 6FBRE16 reach truck).

- Runs entirely in the browser. Nothing is sent to a server and nothing is stored online.
- At the end the operator saves the check as a PDF on their own phone, or shares it with the phone's share menu.
- Opening the page with a model in the address (for example `#7fbe15`) pre-selects that model.

The checklist items are general guidance. Check them against your site's own procedures and the manufacturer's manuals.
